# 哔哔空间 / BBSpace 修改版

本项目基于 [BBSpace](https://github.com/naaammme/bbspace) 二次修改与维护，原作者：[naaammme](https://github.com/naaammme)。

- 当前仓库：https://github.com/Flyoverisblind/new-bbspace
- 下载地址：https://github.com/Flyoverisblind/new-bbspace/releases

## 新增与修复

- 合集 / 分 P 连播，支持播放全部
- 循环播放、自动下一个、播完暂停
- 播放页合集面板
- 收藏夹视频播放全部
- UP 主直播回放
- 修复「需要4k」设置自动关闭
- 修复录播接口 JSON 解析错误

## 构建

系统要求：Android 7.0 及以上

开发环境：JDK 17、Android SDK 36

```bash
./gradlew assembleRelease
```
